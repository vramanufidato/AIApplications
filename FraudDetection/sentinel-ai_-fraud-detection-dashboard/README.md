# Sentinel AI Fraud Detection

## Setup Instructions

1. **Environment Variables**:
   - `GEMINI_API_KEY`: Required for AI-powered risk explanations.
   - `APP_URL`: Automatically set in AI Studio.

2. **Features**:
   - **Real-time Monitoring**: Simulated transaction stream.
   - **Anomaly Detection**: Visualizing outliers in high-dimensional space.
   - **Precision-Recall Analytics**: Interactive PR curves and Confusion Matrices.
   - **AI Risk Assessment**: Detailed explanations of fraudulent patterns using Gemini.

3. **Tech Stack**:
   - **Frontend**: React, Tailwind CSS, Recharts, Motion.
   - **Backend**: Express (for API simulation), Better-SQLite3 (for transaction history).
   - **AI**: Google Gemini API.
